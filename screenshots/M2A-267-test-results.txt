================================================================================
CORE FEATURES IMPLEMENTED
================================================================================

1. Git Integration
   - Automatically captures git commit hash with test results
   - Stores baseline and current commit for comparison
   - Enables traceability across code changes

2. Regression Detection
   - Detects newly failing tests (CRITICAL severity)
   - Monitors pass rate drops (HIGH severity)
   - Tracks cost increases >20% (MEDIUM severity)
   - Identifies latency increases >50% (LOW severity)
   - Detects missing tests from baseline

3. Baseline Management
   - Save test results as named baselines
   - List available baselines with metadata
   - Retrieve appropriate baseline (latest, by tag, manual)
   - Support multiple baseline strategies

4. Rich Reporting
   - Color-coded severity levels (Critical/High/Medium/Low)
   - Side-by-side baseline vs current comparison
   - Detailed issue breakdown with values
   - Both Rich console and plain text formats

5. CI/CD Integration
   - `mcp-eval baseline save` - Save results as baseline
   - `mcp-eval baseline list` - List available baselines
   - `mcp-eval regression <current> <baseline>` - Compare runs
   - `mcp-eval ci-run <path>` - Run tests and exit with CI code
   - Exit code 0 = pass, 1 = regression detected
